# SMA birthday card page

Static page (GitHub Pages) showing a personalised birthday greeting for Singapore Malayalee Association members:

    https://vinodvoa.github.io/sma-birthday-card/?name=Constance&card=b

`name` is shown as plain text (max 40 characters). `card` picks `cards/card_<letter>.jpg`; a missing or unknown card falls back to card a. Links are generated by `npo_dashboard/tools/todays_birthdays.py`, which owns the list of available cards. No member data is stored here.
